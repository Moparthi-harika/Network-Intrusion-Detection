About
IntrusionGuard is a platform designed to safeguard military networks by providing insights into simulated intrusions within LAN environments. It plays a crucial role in analyzing various security breach scenarios and enhancing network defense mechanisms.
This project focuses on using both qualitative and quantitative attributes to detect intrusions, perform real-time threat analysis, and assess network vulnerabilities.

Scenarios
1. Intrusion Detection and Classification
Models are developed using 41 features (3 qualitative and 38 quantitative) to identify and classify network connections as either normal or anomoly, improving detection accuracy.
2. Network Vulnerability Assessment
Detailed analysis of simulated attacks helps identify weak points in network infrastructure, enabling the development of strategies to strengthen defense against future intrusions.

Features
41 detailed connection features (qualitative and quantitative)
Detection and classification of multiple attack types
Vulnerability assessment for military-grade networks
